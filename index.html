How It Works

  1. Choose the card you want to call.
  2. Players choose the number of rounds before the game starts.
  3. Cards deal automatically P1 → P2 → P3 → P4 → P1 → ... until the called card is received.
  4. If nobody receives the called card, the SAME round continues automatically.
  5. Any player can call the card at the start of each round.
  6. The player who receives the called card wins that round.
